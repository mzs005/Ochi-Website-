Ochi Project
This project is a modern, visually appealing website built with React and Vite. It features a variety of components designed to create an engaging user experience, including animated elements, interactive sections, and a responsive layout. The project leverages several libraries and tools to enhance its functionality and maintainability.

Features
Navbar: A fixed navigation bar with links to different sections of the website.
Landing Page: An eye-catching landing page with animated text and images.
Marquee: A scrolling marquee with repeating text animations.
About Section: A detailed section describing the company's approach and services.
Eyes Component: An interactive component that tracks the user's mouse movements.
Featured Projects: A section showcasing featured projects with hover animations.
Cards: A card-based layout displaying various logos and information.
Footer: A comprehensive footer with contact information and social media links.
Technologies Used
React: A JavaScript library for building user interfaces.
Vite: A fast build tool and development server.
Tailwind CSS: A utility-first CSS framework for styling.
Framer Motion: A library for creating animations.
Locomotive Scroll: A smooth scrolling library.
React Icons: A collection of popular icons for React.
